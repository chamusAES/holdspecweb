    A commissioning job, start to finish

    From first scan to signed handover.

    The same five steps on every job. HoldSpec does the repetitive parts and keeps the tech in control of anything that commands equipment.

    1CONNECT

    Discover

    Scan the BACnet network, directly or through the Niagara supervisor. Every controller and point is inventoried.

    2MODEL

    Map

    Match messy point names to known equipment roles. Teach it once and it applies to every unit of that type.

    3PLAN

    Rehearse

    A dry run shows every command HoldSpec would send, and which tests are ready or blocked, before anything moves.

    4TEST

    Run

    Overnight, HoldSpec drives each sequence, watches the response, and restores every point it touched.

    5PROVE

    Hand over

    Findings go to work orders, retests close them, and the owner receives signed checklists and evidence.

    Honest verdicts

    Five answers. No gray area painted green.

    A test that could not run is not a pass. HoldSpec keeps every outcome distinct all the way to the signed report, so owners see what was proven and what is still open.

    Evidence, not a signature on a form

    Every verdict carries its receipts.

    Each run is sealed with the trend, the commands sent, the limits applied and the code requirement it satisfies. If a result is ever questioned, the data is right there.

    Safety by design

    Every command is borrowed, and always given back.

    When HoldSpec tests a unit, each point it commands is taken on a timed lease and journaled. When the test ends, or if anything goes wrong, the point is released and HoldSpec confirms it is back to where it started. Your staff's fault detection view has no way to write to equipment at all.
